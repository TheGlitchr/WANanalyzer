# Repository images

The README uses the same Signal Orbit artwork embedded in the Windows EXE and a capture of the running Monitor interface. The screenshot shows the live interface, including eight trace hops and the latency/loss charts.

`images/social-preview.png` is a 1280 x 640 GitHub social-preview image made from the existing app icon. Regenerate it on Windows with `./scripts/generate-social-preview.ps1`.

To apply the image, open [repository Settings](https://github.com/TheGlitchr/WANanalyzer/settings), find **Social preview**, choose **Edit → Upload an image**, and select `docs/images/social-preview.png`. GitHub uses that image when the repository link is shared. [GitHub's social-preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview) describes the setting and image dimensions.
